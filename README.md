# Visual Progression: Medieval Overhaul Meals

A RimWorld 1.7 mod. Meals cooked before your colony reaches the industrial age use Medieval Overhaul's
meal art. Meals cooked after use the normal art. Old meals keep their look until they're eaten, so the
change happens slowly.

## How it works

It lists simple, fine and lavish meals for Visual Progression Framework, which gives each meal its look
when it's cooked. It's XML only and contains no art. It points at Medieval Overhaul's own images.

Requires Visual Progression Framework and Medieval Overhaul.
